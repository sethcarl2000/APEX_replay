# APEX_replay

This code is meant to take raw APEX CODA data, and output `.root` files which contain VDC tracks. 

## Bash scripts

[Bash script documentation](./docs/scripts.md)
Executable bash scripts in the `scripts` directory. 

In particular, see [run_full_replay.sh](./docs/scripts.md#run_full_replaysh) for the script responsible for automatically executing the full replay workflow from start to finish.
